# İzlek 1.0.0

İzlek'in ilk kararlı sürümü; film ve dizi takibini hesap ya da cloud backend
gerektirmeden Linux masaüstüne getirir.

## Ana özellikler

- Film ve diziler için İzlenecek, İzleniyor ve İzlendi durumları
- Bölüm ilerlemesi, tek bölüm/sezon/tüm dizi işaretleme ve Devam Et
- Favoriler, sıralanabilir özel listeler ve yerel izleme istatistikleri
- TMDB araması, detayları, Discover sonuçları, öneriler ve görseller
- Türkiye için JustWatch kaynaklı izleme sağlayıcısı bilgileri
- Sürümlü İzlek JSON dışa/içe aktarma
- Klavye ile gezinilebilen Türkçe Qt Quick arayüzü

## Kurulum

### AppImage

1. `Izlek-1.0.0-x86_64.AppImage` dosyasını indirin.
2. `chmod +x Izlek-1.0.0-x86_64.AppImage` çalıştırın.
3. `./Izlek-1.0.0-x86_64.AppImage` ile başlatın.

FUSE olmayan sistemlerde:

```bash
APPIMAGE_EXTRACT_AND_RUN=1 ./Izlek-1.0.0-x86_64.AppImage
```

### Debian / Ubuntu

```bash
sudo apt install ./izlek_1.0.0_amd64.deb
```

Paket kaldırma işlemi kullanıcının XDG data, config ve cache dizinlerindeki
veritabanını, tokenı veya ayarları silmez.

## TMDB gereksinimi

Arama, Discover ve çevrimiçi metadata için kullanıcının kendi TMDB API Read
Access Token'ı gerekir. Token ilk açılışta doğrulanır ve sistem anahtarlığında;
anahtarlık yoksa yalnızca kullanıcı tarafından okunabilen yerel config
dosyasında saklanır. Release ve test workflow'ları kişisel TMDB tokenı kullanmaz.

## Privacy / local-first

İzlek hesap oluşturmaz, analytics içermez ve cloud backend kullanmaz. Takip
durumları, bölüm ilerlemesi, favoriler ve özel listeler yalnızca cihazdaki
SQLite veritabanında tutulur. TMDB tokenı, yerel takip verisi ve cache yolları
export dosyasına eklenmez. Daha önce kaydedilen kütüphane çevrimdışı açılabilir.

## Bilinen sorunlar

- Bu sürümün binary paketleri yalnızca x86_64/amd64 Linux içindir.
- Canlı arama, Discover ve metadata yenilemesi internet bağlantısı ile geçerli
  bir TMDB tokenı gerektirir.
- **Yayın engeli:** About/Credits ekranında TMDB'nin resmî onaylı logosu henüz
  yoktur ve logo prominence kontrolü tamamlanmamıştır.
- **Yayın engeli:** SQLite TMDB metadata/provider cache'i için kişisel takip
  verisini koruyan 180 günlük fiziksel retention henüz uygulanmamıştır.
