# İzlek 1.1.0

Film ve dizi kütüphanesi, bölüm ilerlemesi, özel listeler ve yerel
istatistikler için Linux ve Windows masaüstü uygulaması.

## Bu sürümde

- İzlenebilir meta veri kaynakları (TMDb varsayılan; Trakt / TVmaze / OMDb)
  ve izleme bölgesi ayarı.
- Trakt / Letterboxd içe aktarma; Keşfet için DiscoverService ve sana özel
  öneri şeridi.
- Akıllı listeler, kullanıcı etiketleri, koyu/açık tema ve çok dilli arayüz.
- `watched_at` / yeniden izleme sayacı; zenginleştirilmiş istatistikler ve
  JSON şema v4.
- TMDb koleksiyon/seriden özel listeye film ekleme; sağlayıcı grupları.
- Windows 10/11 x64 EXE kurulum paketi (tag yayınıyla birlikte).
- Nix paket CI kararlılığı ve sürüm/indirme dürüstlüğü güncellemesi.

## Kurulum

Yalnız bu yayın sayfasına eklenmiş dosyalar hazır indirilebilir paketlerdir.
Checksum dosyaları indirilen dosyaların bütünlüğünü kontrol etmek içindir.

### Windows EXE — Windows 10/11 x64

`Izlek-1.1.0-windows-x64-setup.exe` dosyasını çalıştırın.

### AppImage — x86_64 Linux

```bash
chmod +x Izlek-1.1.0-x86_64.AppImage
./Izlek-1.1.0-x86_64.AppImage
```

Ubuntu 22.04/24.04 hedeflenir; glibc 2.35 veya üzeri gerekir.
FUSE bulunmuyorsa `APPIMAGE_EXTRACT_AND_RUN=1` ile çalıştırılabilir.

### DEB — Debian / Ubuntu amd64

```bash
sudo apt install ./izlek_1.1.0_amd64.deb
```

### RPM — Fedora x86_64

RPM, tag akışına otomatik eklenmez; doğrulanmış build sonrası ayrıca
yüklenebilir. Yüklendiyse:

```bash
sudo dnf install ./izlek-1.1.0-1.fc43.x86_64.rpm
```

### Snap — amd64

Snap Store imzası olmayan yerel paket için (asset varsa):

```bash
sudo snap install --dangerous ./izlek_1.1.0_amd64.snap
sudo snap connect izlek:password-manager-service
izlek
```

### Nix / NixOS

```bash
nix run github:Teknoloji-Filozoflari/Izlek/v1.1.0
```

## Veri ve gereksinimler

İlk açılışta kendi TMDB API Read Access Tokenınız gerekir. SQLite takip
verileri, listeler ve bölüm ilerlemesi cihazınızda kalır. Token export'a veya
loglara yazılmaz; anahtarlık yoksa kullanıcıya açık config dosyasında saklanır.
Uygulama sürümünü güncellemeden önce Ayarlar'dan JSON yedeği alabilirsiniz.

Binary paketler x86_64/amd64 (ve Windows x64) içindir. AUR ve Snap Store
yayını bu sürümün kapsamına dahil değildir.
