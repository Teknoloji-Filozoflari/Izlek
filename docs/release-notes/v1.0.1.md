# İzlek 1.0.1

Film ve dizi kütüphanesi, bölüm ilerlemesi, özel listeler ve yerel
istatistikler için Linux masaüstü uygulaması.

## Bu sürümde

- Daha hızlı sekme geçişleri ve görselleri kart bazında güncelleme.
- Kütüphane görsellerini indirip yerelde koruma; listelere içerik eklerken arama.
- Detaydan kütüphaneden kaldırma; Devam Et'te yalnız kütüphanedeki diziler.
- Oyuncu fotoğrafları, düzenli film/dizi bilgileri ve yalnız öneriler bölümü.
- Süresi bilinmeyen içerikleri süre toplamından çıkaran istatistikler.
- JSON aktarımı, worker kapanışı ve metadata saklama düzeltmeleri.
- Resmî TMDB logosu ve kişisel veriyi koruyan metadata bakım işlemi.
- AppImage, DEB, RPM, Snap ve Nix paketleme tanımları.

## Kurulum

Yalnız bu yayın sayfasına eklenmiş dosyalar hazır indirilebilir paketlerdir.
SHA256SUMS dosyası indirilen dosyaların bütünlüğünü kontrol etmek içindir.

### AppImage — x86_64 Linux

```bash
chmod +x Izlek-1.0.1-x86_64.AppImage
./Izlek-1.0.1-x86_64.AppImage
```

Ubuntu 22.04/24.04 hedeflenir; glibc 2.35 veya üzeri gerekir.

FUSE bulunmuyorsa `APPIMAGE_EXTRACT_AND_RUN=1` ile çalıştırılabilir.

### DEB — Debian / Ubuntu amd64

```bash
sudo apt install ./izlek_1.0.1_amd64.deb
```

### RPM — Fedora x86_64

```bash
sudo dnf install ./izlek-1.0.1-1.fc43.x86_64.rpm
```

Fedora 43 için üretilir; diğer RPM dağıtımları ayrıca doğrulanmalıdır.

### Snap — amd64

GitHub'dan indirilen Snap Store imzası olmayan yerel paketi kurmak için:

```bash
sudo snap install --dangerous ./izlek_1.0.1_amd64.snap
sudo snap connect izlek:password-manager-service
izlek
```

Snap Store yayını yapılmaz; strict confinement kullanılır. Snap kütüphanesi
sistem kurulumundan ayrı `~/snap/izlek/common` altında tutulur.

### Nix / NixOS

```bash
nix run github:Teknoloji-Filozoflari/Izlek/v1.0.1
```

## Veri ve gereksinimler

İlk açılışta kendi TMDB API Read Access Tokenınız gerekir. SQLite takip
verileri, listeler ve bölüm ilerlemesi cihazınızda kalır. Token export'a veya
loglara yazılmaz; anahtarlık yoksa kullanıcıya açık config dosyasında saklanır.
Uygulama sürümünü güncellemeden önce Ayarlar'dan JSON yedeği alabilirsiniz.

Binary paketler x86_64/amd64 içindir. Açılış testleri offscreen yapılır;
her Linux masaüstü/ekran sürücüsünde çalışma garantisi değildir. AUR ve
Snap Store yayını bu sürümün kapsamına dahil değildir.
