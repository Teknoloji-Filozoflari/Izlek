# Güvenlik Politikası

İzlek henüz geliştirme aşamasındadır; desteklenen kararlı sürüm yoktur. Güvenlik
açığı bulursanız herkese açık issue veya PR içinde exploit, token ya da kişisel
veri paylaşmayın. Repository'nin GitHub **Report a vulnerability** / özel
güvenlik bildirim kanalını kullanın. Bu kanal etkin değilse hassas ayrıntı
vermeden bakımcılardan özel iletişim kanalı isteyin.

Bildirimde etkilenen sürümü, işletim sistemi ve ortamı, yeniden üretme
adımlarını, olası etkiyi ve geçici azaltmayı belirtin. TMDb token'larını,
SQLite dosyalarını veya gerçek kullanıcı verilerini eklemeyin; gerekiyorsa
maskelenmiş ve en küçük örneği paylaşın.

Bakımcılar bildirimi aldıklarını makul bir süre içinde teyit eder, etkiyi
inceleyip düzeltmeyi ve kullanıcıları uygun bir release/changelog notuyla
bilgilendirmeyi planlar. Public issue yalnızca düzeltme yayımlandıktan sonra
veya bakımcıların yönlendirmesiyle açılmalıdır.
